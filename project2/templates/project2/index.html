4. Global Feature Effect Trilogy (PDP, M-Plot, ALE)

Compare Partial Dependence (Marginal), M-Plots (Conditional), and Accumulated Local Effects (Accumulated) across species.

Theoretical Analysis

For which model can you compute ALE partial derivatives exactly? For which do you have to use a discretization?

Decision Tree (Discretization Required): A decision tree is a piecewise constant step function. Within any leaf partition, the prediction is constant and the local partial derivative is zero everywhere:

∂ f(x) ∂ xm  = 0  (inside any leaf partition)

At split thresholds, the prediction undergoes discontinuous step jumps where the derivative is undefined. Consequently, ALE cannot be computed via smooth integration of analytical derivatives; instead, it requires finite-difference interval discretization (quantile binning).

Logistic Regression (Exact Analytical Derivatives): Logistic regression predicts species probabilities through the smooth, continuously differentiable softmax function:

P(Y = k | x) = σ(zk) = ezk ∑j ezj

Because the softmax probability surface is everywhere smooth, its gradient with respect to continuous feature xm can be evaluated analytically and exactly:

∂ P(Y = k | x) ∂ xm  =  P(Y = k | x)  · [ wkm − ∑j P(Y = j | x) · wjm ]

Our implementation automatically computes and accumulates this exact analytical derivative directly when Logistic Regression is selected.

Partial Dependence Plot (PDP)

Marginal distribution: averages across all penguins (may probe unrealistic feature pairs).

Marginal Plot (M-Plot)

Conditional distribution: averages over observed neighbors, but confounds correlated feature effects.

Accumulated Local Effects (ALE)

Accumulates local differences/gradients, isolating true feature effect without confounding.
