2. Architecture Explanation and Justification

2.1. Learning to Defer Methods

We compare two main families of Learning to Defer policies in our experiments, each containing specific decision-routing methods:

1. Post-Hoc Routing (Frozen SVM)

Setup: A baseline SVM classifier is pre-trained on a standard classification task and its parameters are frozen. A routing model is trained post-hoc to estimate whether the baseline classifier is likely to be correct compared to the expert's learned competence profile for a given sample.

Pros: Extremely easy to deploy in production since the core classification model does not need to be retrained or modified.

Cons: Suboptimal compared to joint training because the classifier cannot adjust its predictions to complement the expert (i.e., it does not co-adapt).

• Confidence threshold Policy:

Description: Compares the classifier's predicted margin (difference between top class scores) against a pre-selected confidence threshold. If confidence falls below this threshold, the decision is routed to the expert.

Pros/Cons: Simple and requires no active learning queries, but routes blindly without considering the expert's competence.

• Competence-aware Policy:

Description: Complements the classifier confidence by comparing it directly to the expert's estimated competence profile (learned class-by-class during the active query phase).

Pros/Cons: Highly intelligent routing; prevents harmful deferrals to incompetent experts, but relies heavily on accurate competence estimates.

2. Learning to Defer (Joint Training) - L2D

Setup: The classifier and the router are trained jointly from scratch. The loss function is modified to optimize the human-AI system as a whole, encouraging the classifier to specialize in cases where the expert is weak or unavailable, while delegating to the expert where they excel.

Pros: Yields higher global accuracy because the classifier and router co-adapt.

Cons: Requires full access to all expert labels for the training set during training, which is computationally expensive and logistically difficult. It also requires rebuilding/retraining the entire system from scratch.

• L2D (with linear model) Policy:

Description: A linear classifier and a linear routing model are jointly trained to minimize a surrogate loss function designed to represent team error.

Pros/Cons: Fast training and highly interpretable decision boundaries, but limited capacity to represent complex non-linear classification spaces.

• L2D (with neural network) Policy:

Description: A multi-layer neural network classifier and a neural routing network are jointly optimized.

Pros/Cons: Capable of modeling highly complex, non-linear classification bounds and human decision regions, but computationally expensive and prone to overfitting.

2.2. Active Learning Workflow

Active learning optimizes the collection of expert labels during the training phase. Rather than querying uniformly at random, active strategies identify where the classifier is uncertain or where the expert demonstrates high competence.

In this system, Active Learning is used to discover expert competence profiles rather than to discover missing dataset labels.

Training Phase: The baseline model evaluations guide the selection of a limited budget (N) of text queries. By querying the expert on these strategic examples, the system learns their topic-specific competence profile.

Testing Phase: Active querying stops. The system passes the baseline model weights and the learned competence profile to a competence-aware deferral policy. At test time, the system compares its own confidence against the expert's learned competence to decide whether to predict internally or defer.

2.3. Design Justification & Alternative Approaches

While active learning can take several forms—Pool-Based Sampling, Stream-Based Sampling, and Membership Query Synthesis—we explicitly chose Pool-Based Sampling.

  • Membership Query Synthesis was rejected because generating synthetic TF-IDF text features yields unnatural, nonsensical text instances that human experts cannot evaluate effectively.
  • Pool-Based Sampling leverages our natural AG News text corpus, ensuring queries remain representative, realistic, and fully human-interpretable.
